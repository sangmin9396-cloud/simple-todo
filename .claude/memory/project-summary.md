# SimpleTodo - 할일 관리 앱

## 프로젝트 정보
- **위치**: `C:\Users\HDS\Desktop\클로드 테스트\simple-todo`
- **기술 스택**: React 19 + Vite + TypeScript + Tailwind CSS
- **데이터 저장**: localStorage

## 주요 기능

### 1. 할일 관리
- 할일 추가/수정/삭제/완료
- 카테고리 분류 (업무/개인/학습/건강/기타)
- 우선순위 설정 (낮음/보통/높음)
- 마감일 및 시간 설정
- **메모 기능** (최대 500 자)

### 2. 반복 할일
- 매일/매주/매월 반복
- 매주 요일 선택 가능
- 반복 시에도 시간 지정 가능
- 다음 일정 생성 버튼 (수동)

### 3. 뷰 기능
- **목록 뷰**: 필터링, 정렬, 카테고리별 확인
- **주간 뷰**: 일주일 단위 일정표
- **월간 뷰**: 한 달 단위 캘린더
- 호버 시 전체 할일 드롭다운 표시
- 할일 클릭 시 상세 모달

### 4. 내보내기
- 텍스트 파일 (.txt)
- 이미지 파일 (.png)

## 최근 변경사항
1. 주간/월간 뷰 호버 드롭다운 구현
2. 메모 기능 추가 및 전체 통합
3. 날짜 매칭 버그 수정
4. 내보내기 기능 추가
5. 할일 상세 모달 추가
