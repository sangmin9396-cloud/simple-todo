# SimpleTodo - 프로젝트 변경사항 요약

## 주요 기능

### 기본 기능
- React + Vite + TypeScript 기반 할일 관리 앱
- Tailwind CSS 스타일링
- localStorage 로 데이터 영속성

### 추가된 기능 (최신 순)

1. **주간/월간 일정 뷰**
   - 마우스 호버 시 전체 할일 목록 드롭다운 표시
   - 스크롤바 지원 (최대 100px 높이)
   - 긴 제목 자동 줄바꿈
   - 날짜 정확히 매칭 (로컬 날짜 문자열 사용)

2. **할일 메모 기능**
   - 할일 등록/수정 시 메모 입력 (최대 500 자)
   - 목록 및 상세 모달에서 메모 표시

3. **파일 내보내기**
   - 텍스트 파일 (.txt) - 날짜별 할일 목록
   - 이미지 파일 (.png) - 화면 캡처 (html2canvas 사용)

4. **할일 상세 모달**
   - 주간/월간 뷰에서 할일 클릭 시 상세 정보 표시
   - 제목, 카테고리, 우선순위, 마감일/시간, 반복, 메모, 생성일 표시

5. **반복 할일 개선**
   - 매일 반복 시에도 시간 지정 가능
   - 다음 일정 생성 버튼 분리 (자동 생성 제거)

## 파일 구조
```
src/
├── components/
│   ├── TodoInput.tsx      - 할일 입력 (메모 포함)
│   ├── TodoItem.tsx       - 할일 항목 (메모 표시/편집)
│   ├── TodoList.tsx       - 메인 목록
│   ├── TodoDetailModal.tsx - 상세 모달
│   ├── WeeklyMonthlyView.tsx - 주간/월간 뷰
│   └── ExportButton.tsx   - 내보내기 버튼
├── hooks/
│   └── useTodos.ts        - 할일 상태 관리
└── types/
    └── index.ts           - 타입 정의 (note 필드 추가)
```

## 최근 수정사항
- 날짜 매칭 버그 수정 (toISOString → 로컬 날짜 문자열)
- 월간/주간 뷰 호버 드롭다운 통일
- 메모 기능 전체 통합
